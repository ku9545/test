# 적정기술학회 QR코드 생성기

인터넷 주소(URL)를 입력하면 QR코드를 만들어 주는 간단한 웹 앱입니다.
QR코드 위에는 **적정기술학회** 라는 문구가, 아래에는 입력한 인터넷 주소가 함께 표기됩니다.

## 사용 방법

1. `index.html` 파일을 **더블클릭** 해서 웹 브라우저로 엽니다. (인터넷 연결 불필요)
2. 입력창에 인터넷 주소를 넣습니다. (`https://` 는 생략해도 자동으로 붙습니다.)
3. **만들기** 버튼을 누르거나 Enter 키를 치면 QR코드가 생성됩니다.
4. **이미지 저장** 으로 PNG 파일을 내려받거나, **주소 복사** 로 주소를 복사할 수 있습니다.

## 특징

- **파일 하나로 끝**: 화면·동작 로직·QR 생성 코드가 `index.html` 한 파일에 모두 들어
  있습니다. 다른 파일이나 인터넷 연결 없이 더블클릭만으로 실행됩니다.
- **완전 오프라인**: 외부 서버에 아무것도 요청하지 않습니다. (인터넷이 끊긴 환경에서도 동작)
- **한글 주소 지원**: UTF-8 바이트 모드로 인코딩하여 한글이 포함된 주소도 처리합니다.
- **검증 완료**: 생성한 QR코드는 독립 디코더(jsQR)와 실제 브라우저(오프라인)에서
  정상 판독됨을 확인했습니다.

## 다른 기기로 옮기기

`index.html` 파일 하나만 복사하면 됩니다. 이메일 첨부, USB, 메신저 등 어떤 방법으로
전달해도 받는 쪽에서 브라우저로 열기만 하면 바로 사용할 수 있습니다.
