# 적정기술학회 QR코드 생성기

인터넷 주소(URL)를 입력하면 QR코드를 만들어 주는 간단한 웹 앱입니다.
QR코드 위에는 **적정기술학회** 라는 문구가, 아래에는 입력한 인터넷 주소가 함께 표기됩니다.

## 사용 방법

1. `index.html` 파일을 웹 브라우저로 엽니다.
2. 입력창에 인터넷 주소를 넣습니다. (`https://` 는 생략해도 자동으로 붙습니다.)
3. **만들기** 버튼을 누르거나 Enter 키를 치면 QR코드가 생성됩니다.
4. **이미지 저장** 으로 PNG 파일을 내려받거나, **주소 복사** 로 주소를 복사할 수 있습니다.

## 특징

- **설치·인터넷 불필요**: QR코드 생성 로직(`qrcode.js`)이 앱 안에 포함되어 있어
  외부 라이브러리 없이 오프라인에서도 동작합니다.
- **한글 주소 지원**: UTF-8 바이트 모드로 인코딩하여 한글이 포함된 주소도 처리합니다.
- **검증 완료**: 생성한 QR코드는 독립 디코더(jsQR)로 정상 판독됨을 확인했습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 화면과 동작 로직 |
| `qrcode.js` | 순수 자바스크립트 QR코드 생성 라이브러리 (버전 1~10, EC 레벨 L·M) |
